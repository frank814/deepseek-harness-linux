## Files

- `voices/<voice id>.safetensors`: the voice embeddings, one per voice; `voices.jsonl` lists every voice with its file, name, voice ID, language, locale, gender, age and description.
- `samples/<language>/<locale>/<gender>/<rank>_<name>_<voice id>.ogg`: the sample linked above for each voice (Phonon S (31M)); `samples/en/characters/` holds the character voices.
- `samples/<model>/<language>/<locale>/<gender>/<rank>_<name>_<voice id>/<style>_<n>.ogg`: five more lines per voice for each model size, with `<model>` one of `31m`, `40m`, `56m` and `98m`.
- All samples are Ogg Opus, mono.
